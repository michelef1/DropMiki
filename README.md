App in PWA x invio files tra dispositivi, nessun dato viene memorizzato, P2P,  creata da Miki by Claude

GUIDA:

Il tuo codice è fisso su questo dispositivo: comunicalo all'altro dispositivo per farti trovare.

Il tuo nome ("Sei visibile come") viene mostrato automaticamente agli altri dispositivi quando ti colleghi: puoi cambiarlo toccandolo.

Aggiungi un dispositivo inserendo il suo codice a 6 caratteri e premendo Connetti.

I dispositivi collegati vengono salvati: al prossimo avvio l'app prova a ricollegarsi da sola, se entrambi hanno la pagina aperta.

Tocca il nome di un dispositivo salvato per rinominarlo, oppure ✕ per rimuoverlo.

Tocca un dispositivo connesso (nella lista o sul radar) per selezionarlo come destinatario, poi trascina un file.

I file viaggiano direttamente tra i due dispositivi: nessun file passa da un server.
