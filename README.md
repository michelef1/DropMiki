## 🚀 Deploy su GitHub Pages

1. **Fork** o crea un nuovo repository
2. Carica i 3 file (`index.html`, `manifest.json`, `sw.js`) + cartella `icons/`
3. Vai in **Settings → Pages**
4. Source: **Branch `main`** / Folder: **`/ (root)`**
5. Clicca **Save** → attendi 1 minuto
6. Il sito sarà online su `https://tuonome.github.io/DropMiki/`
