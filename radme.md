## 🌟 Cos'è DropMiki?

**DropMiki** è una **Progressive Web App** che ti permette di **trasferire file e chattare tra i tuoi dispositivi** in modo semplice, veloce e **senza passare da nessun cloud o server**.

Tutto viaggia **direttamente** tra i tuoi device tramite la tecnologia **WebRTC** (peer-to-peer).

---

## 🎯 A cosa serve?

| Situazione | DropMiki risolve |
|------------|------------------|
| 📱 → 💻 Passare una foto dal telefono al PC | ✅ Trasferimento diretto, senza cavo né email |
| 💻 → 📱 Mandare un PDF dal PC al telefono | ✅ Senza account, senza app store |
| 🔒 Condividere file sensibili | ✅ Nessun file passa da un server |
| 💬 Scambiare messaggi tra device | ✅ Chat integrata peer-to-peer |
| 📎 Inviare immagini in chat | ✅ Con anteprima e download |

## ✨ Funzionalità

### 📁 Trasferimento file
- Trascina o seleziona un file
- Invio **P2P diretto** (WebRTC)
- Barra di avanzamento in tempo reale
- Anteprima immagini ricevute

### 💬 Chat
- Messaggi istantanei tra dispositivi collegati
- Anteprima immagini direttamente in chat
- Notifiche quando arriva un nuovo messaggio
- Cancellazione chat con un tocco

### 📱 QR Code
- **Mostra il tuo QR** → l'altro lo inquadra e si connette
- **Scansiona QR** → veloce e preciso, funziona anche a 30-50 cm
- Vibrazione di conferma al riconoscimento

### 🎨 Personalizzazione
- 🎨 **8 colori sfondo home** (Blu, Nero, Viola, Foresta, Vino, Ambra, Ciano, Grafite)
- 💬 **6 sfondi chat** (Scuro, Nebulosa, Galassia, Muschio, Griglia, Chiaro)
- 🔤 **3 dimensioni carattere** (Piccolo · Medio · Grande)
- 🔊 **Suoni di notifica** stile WhatsApp (ON/OFF)

### 🖼️ Lightbox immagini
- Tocca una foto in chat → si apre **a schermo intero**
- **Pinch-to-zoom** con due dita
- **Doppio tap** per ingrandire
- **Swipe giù** per chiudere
- Tasto **Scarica**

### 📲 Installabile come app
- Aggiungi alla **schermata home**
- Funziona come **app nativa**
- Icona, splash screen, modalità standalone

## 🚀 Come si usa

### 🔧 Installazione

#### Android (Chrome)
1. Apri [DropMiki](https://michelef1.github.io/DropMiki/)
2. Tocca il banner viola **"Installa DropMiki"** _(oppure menu ⋮ → "Installa app")_
3. Conferma → l'icona appare sulla home

#### iPhone / iPad (Safari)
1. Apri [DropMiki](https://michelef1.github.io/DropMiki/)
2. Tocca **Condividi** ⬆ (in basso al centro)
3. Scorri e tocca **"Aggiungi a schermata Home"**
4. Conferma → l'icona appare sulla home

#### PC (Chrome / Edge)
1. Apri [DropMiki](https://michelef1.github.io/DropMiki/)
2. Clicca l'icona **⊕ Installa** nella barra degli indirizzi
3. Conferma → l'app si apre in finestra dedicata
